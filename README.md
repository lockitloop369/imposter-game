# Imposter — free online word party game

**Play it here: https://lockitloop369.github.io/imposter-game/**

Imposter is a free word party game for 3 or more players. Everyone gets the same secret word, except the imposter, who gets a different one. Give clues, discuss, and vote to find the imposter.

- No sign-up and no download: type a name and play in the browser
- Play online with a room code, with voice, video and text chat
- Play in person by passing one phone around
- Short of people? Add AI players
- Secret words in 12 languages: English, Chinese, Spanish, Hindi, Bengali, Telugu, Tamil, Marathi, Arabic, French, Portuguese and Russian
- Can be added to a phone's home screen like an app

## How to play

1. Everyone privately gets a word. The imposter's word is different: everyone gets Lion, for example, and the imposter gets Tiger.
2. Taking turns, each player says one clue word.
3. Discuss, then vote for who you think the imposter is.
4. A caught imposter gets one guess at the real word to steal the win.

## About the files

The game is a plain web page with no server: `index.html`, `game.js` (the game), `bots.js` (the AI players), `sw.js` and `manifest.webmanifest` (so it can be installed and opened without internet). The `.txt` file with a long name is a key that lets search engines confirm this site asked to be listed.
